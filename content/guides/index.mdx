# Guides

Each guide here is a step-by-step walkthrough for a specific task. They assume you have read the relevant [Concepts](/docs/concepts) page and are ready to write code or configuration.

| Guide | When to read |
|---|---|
| [Adding a Provider](/docs/guides/adding-a-provider) | You want to integrate a new LLM provider |
| [Adding a Channel](/docs/guides/adding-a-channel) | You want to support a new communication platform |
| [Adding a Tool](/docs/guides/adding-a-tool) | You want to expose a new capability to the agent |
| [Writing a Skill](/docs/guides/writing-a-skill) | You want to bundle tools + instructions for a task |
| [Deploying with Docker](/docs/guides/deploying-with-docker) | You are running the agent in a container |
| [Hardware Peripherals](/docs/guides/hardware-peripherals) | You are wiring an STM32, RPi, or other board |

> **v1 status:** these guides are skeletons. The walkthrough content will be filled in over the next iterations from the existing rantaiclaw `docs/` material plus deep-scan of `examples/`.
