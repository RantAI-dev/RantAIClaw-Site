Reference content is for **looking things up**. If you want to know what a flag does, what a config key controls, or which channels exist, you are in the right section.

## Where this content comes from

Most reference pages will eventually be **generated** from rantaiclaw source — `--help` output, JSON Schema export, tool registry introspection — to prevent drift. Today the pages are placeholders that link out to the canonical markdown in the [rantaiclaw repo](https://github.com/RantAI-dev/RantAIClaw/tree/main/docs).

**Generation plan:**

| Page | Source | Status |
|---|---|---|

| Config | `cargo run --bin rantaiclaw -- config schema --json` (uses `schemars`) | TODO |

| Skills | Hand-written from spec; the schema itself rarely changes | hand-written |
