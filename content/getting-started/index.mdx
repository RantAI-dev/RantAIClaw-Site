# Getting Started

Three steps to a running agent:

1. **[Install](/docs/getting-started/install)** — single curl command, ~12 MB binary, no Rust toolchain needed.
2. **[First Agent](/docs/getting-started/first-agent)** — `rantaiclaw setup` walks you through provider, persona, and your first channel.
3. **[Verify](/docs/getting-started/doctor)** — `rantaiclaw doctor` confirms everything is wired correctly.

If something breaks along the way, jump to [Troubleshooting](/docs/reference/troubleshooting).
